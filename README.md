# Paradise Nursery Shopping Application

Paradise Nursery is a React and Redux Toolkit shopping application for an online plant nursery.

## Project Details
- Landing page with company information and a Get Started button.
- Product listing page with multiple plant categories.
- Add-to-cart functionality.
- Redux-powered shopping cart.
- Quantity increase/decrease and delete controls.
- Continue Shopping and Checkout buttons.
- Dynamic item count and total cost.

## Technologies
React, JavaScript, CSS, Redux Toolkit and Vite.

## Running the Project
```bash
npm install
npm run dev
```
